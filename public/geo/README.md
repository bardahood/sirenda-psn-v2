# GeoJSON provinsi (belum tersedia)

Letakkan berkas `provinsi.geojson` di folder ini agar halaman `/peta` dan peta usulan
berubah dari lingkaran proporsional menjadi choropleth. Setiap feature wajib memiliki
properti `kode` berisi kode provinsi Kemendagri dua digit (mis. `"31"` untuk DKI Jakarta),
atau ubah nama properti di `config/psn_dashboard.php` (`peta.kode_prop`).
Sumber berkas ditetapkan oleh pemilik produk (Q-12).
